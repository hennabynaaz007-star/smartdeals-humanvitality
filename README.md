# HUMANVITALITY — GitHub Pages

Modern HUMANVITALITY health & wellness website template.

## Included
- Responsive homepage
- Health topic cards and search
- Health tip interaction
- Health tools area
- **Tailoring & Designer Dress Studio** with original educational layout
- Measurement checklist
- Cutting and stitching workflow
- Mobile-friendly design

## GitHub Pages
Upload `index.html` to the repository root, commit the change, then enable:
**Settings → Pages → Deploy from branch → main → / (root)**.

The tailoring section uses original website copy/layout. Exact garment drafting formulas can vary by design, fabric, fit and tailoring method.
